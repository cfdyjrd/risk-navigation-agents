\subsection{系统概览}

本文研究室内移动机器人在部分可观测环境中的高层语义动作选择。时刻 $t$ 的规划输入为 $\mathcal{X}_t=(g_t,r_t,e_t,\mathcal{A}_t)$，分别包含任务目标及进度、机器人状态、环境观测和允许的有限动作集合。系统维护长期历史 $\mathcal{H}_t$，并将其转化为有界、可追溯的风险证据。

图~\ref{fig:overview} 给出整体流程。其数学主线为
\begin{equation}
E_i\rightarrow z_i\rightarrow q_i\rightarrow M_i
\rightarrow(Q_j,c_j)\rightarrow\mathcal{B}_r^*\rightarrow a_t^*,
\label{eq:pipeline-zh}
\end{equation}
即由 L0 经历提取风险状态和单次证据，构造 L1 卡片，聚合 L2 规则，再按角色检索并约束动作选择。Task Advocate、Risk Critic 和 Safety Decision Agent 仅输出结构化建议及证据 ID；确定性约束优化器保留动作选择权，独立 Safety Guard 在执行前复核。

\subsection{L0--L1--L2 分层风险记忆}

分层记忆包含 L0 经历集 $\mathcal{E}_t$、L1 卡片集 $\mathcal{M}_t$ 和 L2 规则集 $\mathcal{Q}_t$。稳定 ID 连接三层来源，使抽象规则可回溯到卡片和原始轨迹。

\subsubsection{L0：具身风险经历表示}

每条 L0 经历 $E_i$ 记录任务目标、机器人与环境状态、动作 $A_i$、结果 $O_i$、失败原因、风险类型与严重度 $\sigma_i\in\{1,\ldots,5\}$、决策以及轨迹来源。不可变的 \code{experience\_id} 链接传感日志、控制记录或人工标注。写入时校验必需字段、结果状态、严重度范围和 ID 唯一性。

确定性投影 $\psi$ 从完整经历中提取风险状态 $z_i=[1-\bar c_i,1-\bar d_i,1-p_i,1-b_i,h_i]$。其中 $\bar c_i$ 和 $\bar d_i$ 是归一化通行余量与障碍物距离，$p_i$ 是观测置信度，$b_i$ 是电量比例，$h_i$ 编码机器人类型、障碍状态和任务等离散条件。前四项方向一致：数值越大表示场景风险因素越强。原始轨迹仍留在 L0 中供审计。

\subsubsection{L1：风险记忆卡}

L1 将动作结果转为单次风险证据 $q_i=(\sigma_i/5)\omega(O_i)\gamma_i$，其中 $\gamma_i\in[0,1]$ 为经历可靠性，结果因子 $\omega(O_i)$ 对 failure、aborted 和 success 分别取 $1$、$0.8$ 和 $0.05$。$q_i$ 是相对风险证据而非碰撞概率。若有显式质量评分则直接得到 $\gamma_i$；否则使用带平滑的历史成功/失败统计。

将 $z_i$ 与 $q_i$ 逐步代入压缩映射，可得 L1 卡片：
\begin{equation}
\begin{aligned}
M_i&=C(E_i)\\
&=\operatorname{Pack}\!\left(\psi(E_i),A_i,O_i,F_i,B_i,\right.\\
&\hspace{3.6em}\left.\frac{\sigma_i}{5}\omega(O_i)\gamma_i,\pi_i\right)\\
&=\operatorname{Pack}\!\left([1-\bar c_i,1-\bar d_i,1-p_i,1-b_i,h_i],\right.\\
&\hspace{3.6em}\left.A_i,O_i,F_i,B_i,
\frac{\sigma_i}{5}\omega(O_i)\gamma_i,\pi_i\right).
\end{aligned}
\label{eq:card-derivation-zh}
\end{equation}
其中 $F_i$ 为失败原因，$B_i$ 为缓解措施与停止条件，$\pi_i$ 保存 \code{memory\_id}、\code{experience\_id} 和来源片段。式~\eqref{eq:card-derivation-zh} 的三行依次表示原始经历、风险状态与结果证据的代入，以及最终卡片表示，从而显式给出 L0 到 L1 的构造过程。

\subsubsection{L2：风险规则与认知演化}

具有相近 $z_i$、风险类型和动作语义的卡片组成模式集合 $\mathcal{I}_j$。聚合器从中提取触发条件、建议与禁止动作、缓解措施及来源 ID，形成规则 $Q_j$。令 $n_j^+$、$n_j^-$ 和 $n_j^0$ 分别为缓解成功、风险失败和未决中止次数；前两类均为可判定证据。采用 $\operatorname{Beta}(\alpha,\beta)$ 先验，规则的证据可靠性为
\begin{equation}
\begin{aligned}
(Q_j,c_j)&=\mathcal{A}(\{M_i\}_{i\in\mathcal{I}_j}),\\
c_j&=\mathbb{E}[\theta_j\mid\mathcal{I}_j]
=\frac{n_j^++n_j^-+\alpha}
{n_j^++n_j^-+n_j^0+\alpha+\beta}.
\end{aligned}
\label{eq:rule-zh}
\end{equation}
这里 $c_j$ 衡量模式获得明确经验支持的程度，不表示风险发生概率。规则在来源数、跨场景一致性和 $c_j$ 达到阈值后由 \textit{candidate} 转为 \textit{active}；矛盾或过期证据可修订触发范围或将其转为 \textit{retired}。每次变化均保留旧版本和来源 ID，从而维持 $Q_j\rightarrow M_i\rightarrow E_i$ 的证据链。

运行时仅匹配 \textit{active} 规则。若命中规则存在共同且未被禁止的建议动作，系统保留其交集；否则，确定性冲突闸门停止执行并请求人工复核。

\subsection{角色条件化的风险感知检索}

给定 $\mathcal{X}_t$，每张卡片形成特征向量 $\phi_i=[\mathrm{sim},\mathrm{sev},\mathrm{rel},\mathrm{rec},\mathrm{fit}]\in[0,1]^5$。前三项来自式~\eqref{eq:card-derivation-zh} 中的风险状态、结果证据和卡片质量，后两项描述时效性与角色适配度。角色权重 $w^{(r)}$ 使 Advocate 强调成功与缓解证据，Critic 强调失败、严重风险和停止条件，Decision 平衡正反案例。

检索同时考虑角色相关性、案例多样性和上下文预算：
\begin{equation}
\begin{aligned}
\mathcal{B}_r^*=\arg\max_{\mathcal{B}\subseteq\mathcal{M}_t}\;&
\sum_{M_i\in\mathcal{B}}(w^{(r)})^\top\phi_i
-\lambda\!\sum_{\substack{M_i,M_j\in\mathcal{B}\\i<j}}d(i,j)\\
\text{s.t. }\;&|\mathcal{B}|\leq K,\quad
\sum_{M_i\in\mathcal{B}}\widehat{\tau}(M_i)\leq B_r .
\end{aligned}
\label{eq:retrieval-zh}
\end{equation}
$d(i,j)$ 根据风险类型、结果和缓解措施计算冗余度，$\widehat{\tau}$ 保守估计卡片 Token 数。当前可复现基线按 $(\mathrm{sim},\mathrm{sev},\mathrm{rel},\mathrm{rec},\mathrm{fit})$ 依次取 $w^{(\mathrm{adv})}=(.35,.05,.20,.05,.35)$、$w^{(\mathrm{crit})}=(.30,.25,.15,.05,.25)$ 和 $w^{(\mathrm{dec})}=(.35,.20,.20,.10,.15)$；消融实验检验各项作用。算法~\ref{alg:retrieval} 使用贪心边际增益近似求解式~\eqref{eq:retrieval-zh}。

证据包包含角色、检索版本、预算使用量、L1 卡片、得分分解、匹配原因和来源 ID，并单独附加命中的 L2 规则。Agent 必须在 \code{cited\_experience\_ids} 与 \code{cited\_rule\_ids} 中声明所用证据；系统拒绝输入包中不存在的 ID。该记录支持审计检索内容、检索原因和实际引用。

三个角色的报告记为 $\mathcal{D}_t$。确定性优化器先根据硬约束和命中的 L2 禁止规则构造可行集 $\mathcal{F}_t$，再使用 Decision 证据包求解
\begin{equation}
\begin{aligned}
a_t^*&=\arg\max_{a\in\mathcal{F}_t}U(a),\\
R(a\mid\mathcal{B}_{\mathrm{dec}}^*)&\leq\rho,\\
Z(a\mid\mathcal{D}_t,\mathcal{B}_{\mathrm{dec}}^*)&\leq\eta.
\end{aligned}
\label{eq:decision-zh}
\end{equation}
$R$ 联合场景风险与式~\eqref{eq:card-derivation-zh} 中的历史证据，$Z$ 综合观测置信度、记忆覆盖和 Agent 分歧；二者均为相对分数。规则冲突、Agent 输出无效、可行集为空或 Safety Guard 拒绝动作时，系统执行 \code{safe\_stop}、\code{observe\_again} 或请求人工复核。由此，式~\eqref{eq:pipeline-zh} 的记忆构造最终闭合到可执行决策。

\begin{algorithmic}[1]
\footnotesize
\Require 状态 $\mathcal{X}_t$，角色集 $\mathcal{R}$，L0 库 $\mathcal{E}$，预算 $\{B_r\}$，上限 $K$
\Ensure 分角色证据包 $\{\mathcal{B}_r\}_{r\in\mathcal{R}}$
\State 校验 $\mathcal{X}_t$、$\mathcal{R}$ 与 $\mathcal{E}$
\State 按式~\eqref{eq:card-derivation-zh} 构造所有 $M_i=C(E_i)$
\For{每个角色 $r\in\mathcal{R}$}
  \State 计算所有 $\phi_i$；初始化候选集 $\mathcal{C}_r$ 与 $\mathcal{B}_r\gets\varnothing$
  \While{$\mathcal{C}_r\neq\varnothing$ 且 $|\mathcal{B}_r|<K$}
    \State 按式~\eqref{eq:retrieval-zh} 的边际增益选取 $M_{i^*}$
    \State 从 $\mathcal{C}_r$ 删除 $M_{i^*}$
    \If{$\widehat{\tau}(\mathcal{B}_r)+\widehat{\tau}(M_{i^*})\leq B_r$}
      \State $\mathcal{B}_r\gets\mathcal{B}_r\cup\{M_{i^*}\}$
    \EndIf
  \EndWhile
  \State 向 $\mathcal{B}_r$ 附加命中的 active L2 规则、得分、原因和来源 ID
\EndFor
\State \Return $\{\mathcal{B}_r\}_{r\in\mathcal{R}}$
\end{algorithmic}
