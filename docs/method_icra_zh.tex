\subsection{系统概览}

本文研究室内移动机器人在部分可观测环境中的高层语义动作选择。时刻 $t$ 的规划输入记为
\begin{equation}
\mathcal{X}_t=(g_t,\,r_t,\,e_t,\,\mathcal{A}_t),
\end{equation}
其中 $g_t$ 为任务目标及进度，$r_t$ 为机器人状态，$e_t$ 为环境观测，$\mathcal{A}_t$ 为当前允许的有限动作集合。系统同时维护长期交互历史 $\mathcal{H}_t$，目标是在避免将完整历史重复送入大语言模型的前提下，利用与当前任务相关的风险经验生成可追溯决策。

整体流程如图~\ref{fig:overview} 所示。历史执行首先被组织为 L0 原始风险经历，并压缩为 L1 Risk Memory Card；跨经历的稳定模式进一步形成 L2 Risk Rule。对于当前状态，风险感知检索器分别为 Task Advocate、Risk Critic 和 Safety Decision Agent 构造角色条件化证据包。三个 Agent 仅产生结构化语义建议，并通过经历 ID 与规则 ID 声明实际使用的证据。最终动作不由语言模型直接决定，而由确定性约束优化器重新评估，并经过独立 Safety Guard 复核。

令三个角色的报告集合为 $\mathcal{D}_t$，匹配的 L2 规则为 $\mathcal{Q}_t$。优化器首先排除违反硬约束或 L2 禁止规则的动作，再求解
\begin{equation}
a_t^*=\arg\max_{a\in\mathcal{F}_t} U(a),\quad
\text{s.t. } R(a)\leq\rho,\; Z(a)\leq\eta,
\end{equation}
其中 $\mathcal{F}_t\subseteq\mathcal{A}_t$ 为可行动作集合，$U$ 为任务收益，$R$ 联合当前场景与历史记忆估计相对风险，$Z$ 综合观测置信度、记忆覆盖和 Agent 分歧估计相对不确定性。这里的 $R$ 与 $Z$ 是可解释的相对分数，而非经过校准的概率。若 L2 规则冲突、Agent 输出校验失败、不存在合格动作或 Safety Guard 检测到硬约束违反，系统执行 \code{safe\_stop}、\code{observe\_again} 或请求人工复核，实现失效关闭。

\subsection{L0--L1--L2 分层风险记忆}

分层记忆同时解决三个问题：以统一结构表达具身风险经历，在有限上下文内压缩长期历史，以及保留抽象规则到原始案例的证据链。记忆图记为
\begin{equation}
\mathcal{G}_t=(\mathcal{E}_t,\mathcal{M}_t,\mathcal{Q}_t,\mathcal{L}_t),
\end{equation}
其中 $\mathcal{E}_t$、$\mathcal{M}_t$ 和 $\mathcal{Q}_t$ 分别表示 L0、L1 和 L2 节点，$\mathcal{L}_t$ 保存稳定 ID 之间的来源链接。

\subsubsection{L0：具身风险经历表示}

L0 保存能够支持事后核查和重新抽象的完整交互证据。第 $i$ 条经历写为
\begin{equation}
E_i=(G_i,S_i,A_i,O_i,F_i,K_i,D_i,P_i),
\end{equation}
其中 $G_i$ 为任务目标，$S_i$ 统一包含机器人与环境状态，$A_i$ 为执行动作，$O_i$ 为动作结果，$F_i$ 为失败原因，$K_i$ 为风险类型与严重度，$D_i$ 为当时的决策，$P_i$ 为轨迹来源及时间信息。该表示将“机器人在何种任务和环境下采取何种动作、产生何种后果以及风险为何发生”绑定在同一记录中，避免只保存孤立的成功率或自然语言教训。

每条 L0 经历具有不可变的 \code{experience\_id}，并可链接传感日志、控制记录或人工标注。经历校验至少检查必需字段、结果状态、严重度范围和 ID 唯一性。原始信息不直接全部进入 Agent 上下文，而作为后续压缩与审计的证据底座。

\subsubsection{L1：风险记忆卡}

L1 通过确定性压缩映射 $C$ 将完整经历转化为紧凑风险记忆卡：
\begin{equation}
M_i=C(E_i)=(T_i,H_i,A_i,O_i,F_i,B_i,Q_i,P_i),
\end{equation}
其中 $T_i$ 为触发条件，$H_i$ 为危险类型与严重度，$B_i$ 包含缓解措施和停止条件，$Q_i$ 包含支持次数、可靠性及最近验证时间，$P_i$ 保留来源。触发条件只保留对风险判别必要的状态，例如通行余量、障碍物距离、观测置信度和电量，而删除冗长轨迹中的重复描述。

每张卡具有稳定的 \code{memory\_id}，并显式保存其 \code{experience\_id} 和来源片段。因而，压缩不会切断证据链：Agent 可以使用短卡片进行推理，审计者仍可沿 $M_i\rightarrow E_i$ 回查原始轨迹。卡片还保存检索得分分解和匹配原因，使“为何该经历进入上下文”可被复现。

\subsubsection{L2：风险规则与认知演化}

L2 将多个相关 L1 卡片中的稳定风险模式表达为条件规则
\begin{equation}
Q_j=(C_j,K_j,A_j^{+},A_j^{-},B_j,N_j,c_j,z_j),
\end{equation}
其中 $C_j$ 为触发条件，$K_j$ 为风险类型，$A_j^{+}$ 与 $A_j^{-}$ 分别为建议和禁止动作，$B_j$ 为缓解措施，$N_j$ 为来源记忆 ID 集合，$c_j$ 为置信度，$z_j\in\{\text{candidate},\text{active},\text{retired}\}$ 为生命周期状态。规则仅在触发条件满足时参与当前决策；其来源集合提供 $Q_j\rightarrow M_i\rightarrow E_i$ 的完整追溯路径。

长期交互通过增量证据推动风险认知演化。新轨迹首先形成 L0 经历，相似经历更新 L1 的支持统计与可靠性；反复出现且得到足够支持的模式形成或强化候选 L2 规则。与既有规则矛盾的新证据可降低其置信度、修订触发范围或使其停用。该过程使安全边界由静态提示转化为随经验证据更新的知识边界，同时避免一次偶然失败直接生成强规则。

运行时仅匹配 \textit{active} 规则。若多条命中规则仍存在共同且未被禁止的建议动作，系统保留该交集；若不存在共同安全建议，确定性冲突闸门不调用 LLM 仲裁，而是停止并请求人工复核。该设计将经验规则的不一致显式暴露出来，防止模型按语言置信度隐式选择互斥规则。

为使长期更新可复现，每个风险模式维护统计量 $n_j=(n_j^{+},n_j^{-},n_j^{0})$，分别表示缓解成功、风险失败和人工中止的支持次数。缺少显式质量标注时，规则可靠性可由带平滑的证据估计给出：
\begin{equation}
c_j=\frac{n_j^{+}+n_j^{-}+\alpha}
{n_j^{+}+n_j^{-}+n_j^{0}+\alpha+\beta},
\end{equation}
其中 $\alpha,\beta>0$ 防止少量样本产生极端置信度。候选规则只有在来源数、跨场景一致性和最低置信度同时满足时才转为 \textit{active}；持续冲突、长期未验证或被反例否定的规则降为 \textit{candidate} 或 \textit{retired}。所有状态变化创建新版本并保留旧版本及触发更新的来源 ID，使安全边界的变化本身也可审计。

该演化过程区分“风险发生的证据”和“缓解有效的证据”。失败案例用于识别禁止动作及停止条件，成功案例用于验证缓解措施不会导致永久停止。只有同时覆盖风险与缓解的规则才能扩展到相似场景，从而降低系统因累积失败记忆而不断趋于保守的风险。

\subsection{角色条件化的风险感知检索}

给定当前输入 $\mathcal{X}_t$ 和角色 $r\in\{\mathrm{adv},\mathrm{crit},\mathrm{dec}\}$，检索器首先计算 L0 经历与当前场景的透明相似度。比较因素包括机器人类型、障碍物状态、通行余量、障碍物距离、观测置信度和任务目标。仅保留具有正相似度的候选，再对每条候选计算
\begin{equation}
s_i^{(r)}=\sum_{k\in\mathcal{K}}w_k^{(r)}\phi_{ik},\quad
\mathcal{K}=\{\mathrm{sim},\mathrm{sev},\mathrm{rel},\mathrm{rec},\mathrm{fit}\},
\end{equation}
其中 $\phi_{ik}\in[0,1]$ 分别表示场景相似度、风险严重度、证据可靠性、时效性和角色适配度；$w_k^{(r)}$ 为角色相关权重且和为 1。可靠性优先使用显式质量评分；当只有成功/失败统计时，使用带平滑的后验均值，避免单次观测产生过度确定性。时效性使用随验证间隔衰减的函数。

角色条件化体现在 $w_k^{(r)}$ 与 $\mathrm{fit}$ 的共同作用。Advocate 强调可迁移的成功经历和有效缓解措施；Critic 提高失败、高严重度和停止条件证据的优先级；Decision 使用较平衡的正反案例以支持最终裁决。因此，三个角色并非在同一证据包上仅更换提示词，而是在推理前即获得不同的经验分布。

当前原型采用如下可审计基线权重，分量顺序为 $(\mathrm{sim},\mathrm{sev},\mathrm{rel},\mathrm{rec},\mathrm{fit})$：
\begin{align}
w^{(\mathrm{adv})}&=(.35,.05,.20,.05,.35),\\
w^{(\mathrm{crit})}&=(.30,.25,.15,.05,.25),\\
w^{(\mathrm{dec})}&=(.35,.20,.20,.10,.15).
\end{align}
这些权重用于定义透明、可重复的工程基线，而非声称已经从数据中学习得到；后续实验通过消融和敏感性分析检验角色项、严重度项及可靠性项的独立作用。

为避免 Top-$k$ 被重复案例占满，系统采用贪心多样性选择。在已选集合 $S$ 下，下一条记忆为
\begin{equation}
i^*=\arg\max_{i\notin S}\left[s_i^{(r)}-\lambda
\max_{j\in S} d(i,j)\right],
\end{equation}
其中 $d(i,j)$ 根据相同风险类型、结果状态和教训计算冗余度，$\lambda$ 控制相关性与多样性的权衡。候选随后被转换为 L1 卡片，并在预算 $B_r$ 下依次装入角色证据包：
\begin{equation}
\sum_{M_i\in\mathcal{B}_r}\widehat{\tau}(M_i)\leq B_r,
\end{equation}
其中 $\widehat{\tau}$ 是针对中英文 JSON 的保守 Token 估计。超过预算的卡片被跳过，从而使历史规模增长时 Agent 输入仍保持有界。

最终证据包包含角色、检索版本、预算使用量、L1 卡片、逐项得分分解、匹配原因和来源 ID；匹配的 L2 规则作为跨经历证据单独附加。Agent 输出必须在 \code{cited\_experience\_ids} 与 \code{cited\_rule\_ids} 中声明实际使用的证据，系统拒绝输入包中不存在的 ID。该闭环同时回答了三个审计问题：系统检索了什么、为何检索，以及哪些证据真正影响了建议。

完整检索过程可概括为算法~\ref{alg:retrieval}。设经验库大小为 $N$，每个角色最多选取 $K$ 张卡片。透明特征计算为 $O(N)$，贪心去冗余为 $O(NK)$；由于 $K$ 由提示预算固定，在线检索开销随历史规模近似线性增长。三个角色可共享场景特征计算，但分别完成角色精排和预算装包。

\fbox{\begin{minipage}{0.91\columnwidth}
\refstepcounter{algo}\label{alg:retrieval}
\textbf{算法~\thealgo：角色条件化风险检索}\\[-2pt]
\textbf{输入：} 当前状态 $\mathcal{X}_t$，角色 $r$，L0 库 $\mathcal{E}$，预算 $B_r$，上限 $K$。\\
1) 校验角色与输入结构；\\
2) 计算每条经历的透明场景相似度；\\
3) 计算严重度、可靠性、时效性和角色适配度；\\
4) 使用 $w^{(r)}$ 计算角色得分 $s_i^{(r)}$；\\
5) 以式（8）的冗余惩罚贪心选择候选；\\
6) 将候选确定性压缩为 L1 卡片；\\
7) 按式（9）装入 Token 预算并附加匹配 L2 规则；\\
8) 返回含得分分解、匹配原因和来源 ID 的证据包。
\end{minipage}}
\end{center}

综上，分层风险记忆控制长期历史的上下文规模并保留抽象来源，角色条件化检索则把不同风险证据分配给不同审议职责。二者共同为后续确定性动作选择提供可追溯的语义依据，而不将执行权限交给语言模型。
